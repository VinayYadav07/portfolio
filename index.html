ai-mailbox Featured project

AI Mailbox

Mail app where AI reads every mail and finds the work

This is the AI version of my mailbox app. Users send and receive mails, and Gemini AI gives a summary, priority, tasks, deadlines and meetings for every mail. It can also write a reply in the tone you want.

  • AI summary and priority for every mail (Urgent, Important, Normal)
  • Finds tasks, deadlines and meetings, with a daily briefing page
  • Smart reply with tone changer (Professional, Friendly, Concise)
  • API key stays on the server, offline rules work if AI is down
React Firebase Firestore Gemini AI Context API Vercel

travelnest

TravelNest

Travel-stay booking website with an admin panel

Users can search and filter stays like villas, houseboats and cottages, view details, add to cart and book. The admin panel manages listings and approves or rejects bookings, and the user sees the status on their My Bookings page.

  • Search, category and price filters, sorting
  • Login with Firebase Authentication and protected routes
  • Booking form that calculates nights and total price
  • Separate admin panel: listings, categories, approve / reject bookings
React React Router Bootstrap Firebase
Live Demo Admin Panel GitHub (User) GitHub (Admin)
nextmart

NextMart

Online shopping store with secure login, built with Next.js

A products store built with the Next.js 14 App Router to learn how authentication really works. Login creates a JWT signed with jose and stores it in an httpOnly cookie, and middleware checks it before protected pages load.

  • JWT login with jose, stored in an httpOnly cookie
  • Middleware protects pages before they render
  • Products from the DummyJSON API using server components
  • Loading skeletons and a custom 404 page
Next.js 14 App Router React 18 jose (JWT) Middleware CSS
Live Demo GitHub

expense-tracker

Expense Tracker

Personal finance app with Redux Toolkit

Add, edit and delete daily expenses and watch the total update. Includes login with password reset, email verification, dark mode and CSV download for premium users.

  • Redux Toolkit slices for auth, expenses, theme and ui
  • Firebase Authentication and Realtime Database
  • Premium unlocks after ₹10,000 total, with CSV download
  • 20 test cases with Vitest and React Testing Library
React Redux Toolkit Firebase Vitest

the-generics-music-store

E-Commerce Website

Online music store built with the Context API

An e-commerce site for a music store. Users browse albums and merchandise, view product details, add items to the cart and log in. Cart and login data are shared using the Context API and stored with Firebase.

  • Product list and product detail pages with React Router
  • Cart with quantities and total, saved in localStorage
  • Login and protected account pages with Firebase
  • Movies page and contact form using Firebase Realtime Database
React Context API React Router React Bootstrap Firebase
