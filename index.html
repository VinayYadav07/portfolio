TravelNest

Travel-stay booking website with an admin panel

Users can search and filter stays like villas, houseboats and cottages, view details, add to cart and book. The admin panel manages listings and approves or rejects bookings, and the user sees the status on their My Bookings page.

  • Search, category and price filters, sorting
  • Login with Firebase Authentication and protected routes
  • Booking form that calculates nights and total price
  • Separate admin panel: listings, categories, approve / reject bookings
React React Router Bootstrap Axios Firebase

Mailbox Client

Email app to send and receive mail between registered users

A responsive email application built with React and Firebase. Users create an account, log in, compose and send mail to other registered users, read their inbox and check their sent mail.

  • Compose with To, Cc/Bcc, subject and a rich text editor
  • Inbox with unread count, read and delete mail, Sent, Starred, Drafts and custom folders
  • Auth and mail state handled with the Context API and a custom hook
  • Firebase Authentication and Firestore, protected routes, config kept in environment variables
React Vite Context API React Router React Bootstrap Firebase Firestore
Live Demo GitHub

Expense Tracker

Personal finance app with Redux Toolkit

Add, edit and delete daily expenses and watch the total update. Includes login with password reset, dark mode, CSV/Excel export and protected routes.

  • Redux Toolkit slices for auth, expenses, theme and notifications
  • Firebase Authentication and Realtime Database
  • Export expenses to CSV and Excel
  • Light / dark mode with a saved preference
React Redux Toolkit React Router React Bootstrap Firebase

E-Commerce Website

Online music store built with the Context API

An e-commerce site for a music store. Users browse albums and merchandise, view product details, add items to the cart and log in. Cart and login data are shared using the Context API and stored with Firebase.

  • Product list and product detail pages with React Router
  • Cart with quantities and total, saved in localStorage
  • Login and protected account pages with Firebase
  • Contact form and a movies page saved to Firebase
